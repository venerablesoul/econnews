    Данные. Мировые рынки, новости, календарь и сделки — из данных бота (обновление ~раз в 10 минут). Акции США, валюты, металлы и нефть — онлайн через сервер бота. Ключи API хранятся только на сервере: в терминал и в браузер они не попадают.

    Вход владельца. Откройте терминал кнопкой «🖥 Терминал» в чате с ботом — платные данные (мировые рынки онлайн) включатся сами. В обычном браузере — введите пароль владельца.

    Установить как приложение.

    Крипта идёт напрямую с биржи Binance в реальном времени, ключ не нужен. Если Binance недоступен, терминал переключится на CoinGecko (обновление раз в минуту).
