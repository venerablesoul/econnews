# Бот экономических новостей

Каждые ~30 минут собирает экономические новости (ФРС, ЕЦБ, Банк Англии, МВФ, ЦБ РФ, Bloomberg, BBC, Reuters, FT, CNBC, MarketWatch, The Guardian, Коммерсантъ, РБК), переводит их на русский и присылает в Telegram. Работает на GitHub Actions, компьютер не нужен.

## Что приходит в Telegram
- **Новости.** 🔴 важное и 🟡 заметное. У каждой новости заголовок, краткая выжимка в 1–2 предложения, источники и теги (#нефть #ФРС #рубль…). Одна история из разных источников приходит одним сообщением.
- **09:00 МСК.** «Доброе утро»: главное за ночь, события дня из экономического календаря и графики рынков.
- **За час до важных данных.** Напоминание: инфляция США, решения ФРС и ЕЦБ, занятость, ВВП и т. п., с прогнозом и прошлым значением.
- **21:00 МСК.** Итоги дня (топ-10), календарь на завтра и графики рынков.
- **Сбои.** Если источник не отвечает ~3 часа, придёт предупреждение, а когда заработает — сообщение об этом.
- **Ночью (0–8 МСК)** сообщения приходят без звука, кроме 🔴.
- Кнопка **«📈 Рынок онлайн»** открывает страницу с графиками и лентой новостей (GitHub Pages, папка `docs`).

## Терминал
Страница `docs/terminal/` открывается по адресу `https://venerablesoul.github.io/econnews/terminal/` или кнопкой «🖥 Терминал» в Telegram. Это личный терминал в стиле Bloomberg с командной строкой: `WEI`, `FX`, `GLCO`, `RATES`, `CRYPTO`, `N`, `ECO`, `HELP`, а также тикеры `GOLD`, `BTC`, `NASDAQ:AAPL` и т. п.
- **Мировые рынки (индексы, валюты, сырьё, доходности).** Без ключа данные приходят от бота раз в ~30 минут. С ключом EODHD (⚙ → вставить ключ) терминал сам обновляет их каждые 30 секунд. Ключ хранится только в вашем браузере.
- **Крипта** идёт в реальном времени с Binance. Если Binance недоступен, данные берутся из CoinGecko раз в минуту.
- **Графики** строит TradingView.
- **Новости и календарь** берутся из данных бота.

**Установка как приложение:**
- **Компьютер (Chrome/Edge):** откройте терминал и нажмите «⤓ УСТАНОВИТЬ» в шапке или значок установки в адресной строке. Терминал появится на рабочем столе и будет открываться в своём окне.
- **Android:** меню ⋮ → «Добавить на главный экран».
- **iPhone:** Safari → «Поделиться» → «На экран „Домой“».
- **Telegram:** кнопка «🖥 Терминал» под сообщениями. Чтобы терминал был всегда под рукой, в @BotFather выполните `/setmenubutton` и укажите ссылку на терминал.

## Свежесть данных: как ускорить
- **Акции США, валюты, золото и нефть в реальном времени (бесплатно).** Зарегистрируйтесь на finnhub.io, скопируйте API key, затем в терминале нажмите ⚙ → «Ключ Finnhub» → «Сохранить».
- **Фактические значения данных США** («вышло 0,4% при прогнозе 0,3%»). Получите бесплатный ключ на fredaccount.stlouisfed.org/apikeys и добавьте его в GitHub: Settings → Secrets and variables → Actions → New repository secret, имя `FRED_API_KEY`. Бот пришлёт сообщение «📊 Вышли данные», а в календаре терминала появится строка «факт».
- **Новости каждые 5 минут вместо 30.** Запустите бота на сервере или своём компьютере в постоянном режиме, пошаговая инструкция в [deploy/SERVER.md](deploy/SERVER.md).

## Настройки
Файл `.github/workflows/news.yml`, блок `env`. Его можно редактировать прямо на GitHub через ✏️.

| Параметр | Что делает | По умолчанию |
|---|---|---|
| `MIN_LEVEL` | `high` — только 🔴, `medium` — 🔴 и 🟡 | `medium` |
| `DIGEST_HOUR` | час вечерней сводки по МСК, `-1` — выключить | `21` |
| `MORNING_HOUR` | час утреннего дайджеста по МСК, `-1` — выключить | `9` |
| `CHART_HOURS` | когда присылать графики рынков | `9,21` |
| `QUIET_HOURS` | часы без звука по МСК | `0-8` |
| `SUMMARIES` | выжимка под заголовком | `yes` |
| `TAGS` | теги | `yes` |
| `CALENDAR` | календарь событий и напоминания | `yes` |
| `CAL_COUNTRIES` | чьи события показывать | `USD,EUR,CNY,GBP,JPY` |
| `REMIND_MINUTES` | за сколько минут напоминать, `0` — не напоминать | `60` |
| `ALERTS` | оповещения о сбоях источников | `yes` |
| `TERMINAL_BUTTON` | кнопка «Терминал» под сообщениями | `yes` |
| `FRED_API_KEY` | секрет GitHub: факт по вышедшим данным США | — |
| `TRANSLATE` | перевод на русский, `off` — выключить | `ru` |
| `SHOW_ORIGINAL` | показывать оригинал под переводом | `no` |

**Частота** задаётся строкой `cron: "*/30 * * * *"`. Например, `"0 * * * *"` значит раз в час.

**Источники** перечислены в файле `sources.py`. Чтобы добавить источник, допишите строку по образцу. Чтобы убрать, закомментируйте её.

## Полезно знать
- GitHub запускает расписание с опозданием 5–15 минут. Это нормально.
- Файл `state.json` бот ведёт сам: в нём хранится, что уже отправлено, и кэш календаря. Не удаляйте его.
- Календарь берётся из бесплатной ленты Forex Factory. События ЦБ РФ в нём нет, новости о ключевой ставке приходят из ленты ЦБ РФ.
- **Выключить бота:** Actions → Economic news → **⋯** → **Disable workflow**.

## Запуск вручную
Нужен Python 3.9+. Для графиков ещё нужен `pip install matplotlib`.
```bash
export TELEGRAM_BOT_TOKEN="..."
export TELEGRAM_CHAT_ID="..."
python news_bot.py --test      # проверить связь с Telegram
python news_bot.py --dry-run   # напечатать в консоль, ничего не отправляя
```
