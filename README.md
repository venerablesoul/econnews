# EconNews — бот экономических новостей и терминал

- **Бот в Telegram** присылает важные новости мировой экономики на русском, утреннюю и вечернюю сводки, напоминания о важных данных, графики рынков, крупные сделки политиков США и инсайдеров. Подписаться может любой, кто нажмёт /start.
- **Терминал** в стиле Bloomberg: мировые рынки, акции США онлайн, крипта, графики, новости, календарь, сделки.
  Открывается кнопкой «🖥 Терминал» в боте или по адресу `https://venerablesoul.github.io/econnews/terminal/`.

## Как это устроено

| Часть | Где работает | Что делает |
|---|---|---|
| `news_bot.py` (+ `market.py`, `econ_calendar.py`, `trades.py`) | GitHub Actions, workflow **Economic news** | Каждые ~10 минут собирает новости, котировки, календарь и сделки. Рассылает их владельцу и всем подписчикам. Публикует `docs/data.json` для терминала. |
| `worker/` — сервер бота | Cloudflare Workers (бесплатно), workflow **Bot server (Cloudflare)** | Круглосуточно и мгновенно отвечает на /start и команды. Хранит список подписчиков. Отдаёт терминалу котировки, держа ключи API у себя. |
| `docs/` | GitHub Pages | Страница «Рынок онлайн» и терминал. |

Ключи API хранятся только в секретах GitHub и на сервере Cloudflare. В коде, на страницах и в браузере их нет.
Бесплатный ключ (Finnhub) работает для всех. Платный (EODHD) — только для владельца.

## Сервер бота: настройка один раз (≈10 минут)

1. **Аккаунт Cloudflare.** Зарегистрируйтесь на https://dash.cloudflare.com/sign-up (бесплатно, карта не нужна).
2. **Токен Cloudflare.** Откройте https://dash.cloudflare.com/profile/api-tokens → **Create Token** → шаблон **Edit Cloudflare Workers** → **Use template**.
   В «Account Resources» выберите свой аккаунт, в «Zone Resources» — **All zones**. Нажмите **Continue to summary** → **Create Token** и скопируйте токен.
3. **Секреты GitHub.** В репозитории: **Settings → Secrets and variables → Actions → New repository secret**. Добавьте:

   | Имя | Что вписать | Нужен? |
   |---|---|---|
   | `CLOUDFLARE_API_TOKEN` | токен из шага 2 | да |
   | `FINNHUB_API_KEY` | бесплатный ключ с finnhub.io (Dashboard → API key) | да — акции США в терминале для всех |
   | `EODHD_API_KEY` | ваш платный ключ EODHD | для мировых рынков онлайн у владельца |
   | `TERMINAL_PASSWORD` | любой пароль | чтобы входить владельцем из обычного браузера |

   `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` уже есть: их использует основной бот.
4. **Запуск.** **Actions → Bot server (Cloudflare) → Run workflow**. Через 1–2 минуты бот пришлёт вам сообщение «✅ Сервер бота работает».
   Дальше сервер обновляется сам при каждом изменении папки `worker/`.

Проверка: напишите боту /start с другого аккаунта. Ответ придёт сразу, а новости — со следующей проверки (до 10 минут).

## Команды бота

/start — подписаться · /news — главное за сутки · /markets — рынки · /calendar — календарь · /trades — сделки · /stop — отписаться.
Только для владельца: /stats — сколько подписчиков.

## Терминал

- Все видят бесплатные данные: мировые рынки из данных бота (раз в ~10 минут) и акции США онлайн (раз в 30 секунд).
- Владелец видит ещё и мировые рынки онлайн по платному ключу (раз в 15 секунд). Терминал узнаёт владельца сам, если открыть его кнопкой «🖥 Терминал» в Telegram. В обычном браузере: ⚙ → пароль владельца.
- Команды: `HELP` — список; `TRD` — сделки; `N` — новости; `ECO` — календарь; `GOLD`, `BTC`, `AAPL`… — графики.

## Настройки рассылки

Всё в `.github/workflows/news.yml`, блок `env:`. Например: `MIN_LEVEL` (присылать только самое важное), `QUIET_HOURS` (часы без звука), пороги сделок `CONGRESS_MIN`, `INSIDER_MIN_BUY`, `INSIDER_MIN_SELL`.
Свой домен для страниц (например, terminalbloom.com): **Settings → Secrets and variables → Actions → Variables → New repository variable** `PAGES_URL` = `https://terminalbloom.com/`. После этого перезапустите оба workflow.

## Если что-то не работает

- **Бот не отвечает на /start.** Проверьте, что последний запуск **Bot server (Cloudflare)** зелёный. Если красный, откройте его: в шаге с ошибкой написано, чего не хватает.
- **Новости приходят только вам.** Подписчики появятся, когда сервер бота заработает. В журнале **Economic news** видна строка `получателей: N`.
- **Источник перестал отвечать.** Бот сам пришлёт вам предупреждение. Список источников — в `sources.py`.
