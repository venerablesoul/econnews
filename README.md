# Бот экономических новостей → Telegram

Каждые ~30 минут собирает новости, влияющие на экономику, из официальных и крупных источников, переводит их на русский и присылает в Telegram.

**Что приходит:**
- 📰 **Выпуски новостей**: в шапке строка с рынком (S&P 500, нефть, золото, рубль, индекс Мосбиржи, биткоин), ниже разделы 🔴 **Главное** (ставки, инфляция, ВВП, занятость, санкции, пошлины, нефть, кризисы) и 🟡 **Также** (рынки, валюты, торговля, бюджет).
- 📊 **Картинка с графиками** 10 рынков в 9:00 и 21:00 МСК.
- 🗓 **Главное за день** в 21:00 МСК: топ-10 новостей за сутки.
- 📈 **Кнопка «Рынок онлайн»** под сообщениями: открывает прямо в Telegram страницу с живыми графиками TradingView, экономическим календарём и лентой новостей бота.

Если об одном событии пишут несколько источников, оно приходит **одной строкой** со списком всех источников. Чем больше источников, тем выше важность. Новости не по теме (спорт, политика, происшествия, светская хроника) отсеиваются. Ночью (0–8 МСК) сообщения приходят без звука, кроме 🔴.

**Источники новостей:** ФРС, BLS (статистика США), ЕЦБ, Банк Англии, МВФ, ЦБ РФ, Bloomberg, BBC, Reuters, Financial Times, CNBC, MarketWatch, The Guardian, Коммерсантъ, РБК (только экономические рубрики). Список правится в `sources.py`.
**Котировки:** Yahoo Finance, ЦБ РФ, Мосбиржа. Живые графики на странице — TradingView.

## Установка (≈15 минут, один раз)

### Шаг 1. Создайте Telegram-бота
1. В Telegram откройте **@BotFather** и отправьте `/newbot`.
2. Придумайте имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `1234567890:AAH...`. Сохраните его.

### Шаг 2. Узнайте свой chat id
1. Найдите своего бота, нажмите **Start** и напишите ему что угодно.
2. Откройте в браузере ссылку, подставив свой токен:
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
3. Найдите `"chat":{"id":123456789`. Это число и есть **chat id**.

### Шаг 3. Создайте репозиторий на GitHub
1. Зарегистрируйтесь на **github.com**.
2. **+ → New repository**, название `econ-news`, тип **Public**, затем **Create repository**.
   *Public, потому что так GitHub Actions и страница бесплатны без ограничений. Токен в репозиторий не попадает, он хранится в секретах (шаг 6).*

### Шаг 4. Загрузите файлы
1. На странице репозитория нажмите **uploading an existing file**.
2. Перетащите из распакованного архива файлы `news_bot.py`, `sources.py`, `market.py`, `charts.py`, `README.md` **и папку `docs` целиком** (внутри неё `index.html`). Нажмите **Commit changes**.
   *Если папка не перетаскивается: Add file → Create new file, имя `docs/index.html`, вставьте содержимое файла `index.html` и нажмите Commit.*

### Шаг 5. Создайте файл расписания
**Add file → Create new file**, в поле имени введите ровно `.github/workflows/news.yml`, вставьте содержимое файла `news.yml` из архива, затем **Commit changes**.

### Шаг 6. Добавьте секреты
**Settings → Secrets and variables → Actions → New repository secret**, два секрета:

| Name | Secret |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из шага 1 |
| `TELEGRAM_CHAT_ID` | число из шага 2 |

### Шаг 7. Включите страницу «Рынок онлайн»
**Settings → Pages**. В блоке *Build and deployment*: Source **Deploy from a branch**, Branch **main**, папка **/docs**, затем **Save**.
Через 1–2 минуты страница откроется по адресу `https://ВАШ_ЛОГИН.github.io/econ-news/`.

### Шаг 8. Запустите
1. Вкладка **Actions**. Если GitHub спросит, нажмите **I understand my workflows, go ahead and enable them**.
2. **Economic news → Run workflow → Run workflow**.
3. Через 1–2 минуты в Telegram придёт «✅ Бот экономических новостей запущен» с кнопкой «📈 Рынок онлайн».

Дальше бот работает сам, круглосуточно, ваш компьютер не нужен.

### По желанию: оформление бота
В @BotFather:
- `/setuserpic` — аватарка бота;
- `/setdescription` — описание, например «Главные экономические новости и рынки»;
- **Bot Settings → Menu Button → Configure menu button**: вставьте адрес страницы и назовите кнопку «Рынок». Тогда графики будут открываться кнопкой у поля ввода в любой момент, а не только под сообщениями.

## Управление

**Отключить:** Actions → Economic news → **⋯** справа вверху → **Disable workflow**. Включить снова: там же, **Enable workflow**.

**Настройки** (файл `.github/workflows/news.yml`, блок `env`, редактируется на GitHub через ✏️):

| Параметр | Что делает | По умолчанию |
|---|---|---|
| `MIN_LEVEL` | `high` — только 🔴, `medium` — 🔴 и 🟡 | `medium` |
| `DIGEST_HOUR` | час сводки «Главное за день» по МСК, `-1` — выключить | `21` |
| `CHART_HOURS` | часы картинки с графиками по МСК, через запятую; пусто — не присылать | `9,21` |
| `MARKET_LINE` | строка с котировками в шапке выпусков (`yes`/`no`) | `yes` |
| `QUIET_HOURS` | часы без звука по МСК | `0-8` |
| `TRANSLATE` | `ru` — переводить на русский, `off` — оставить оригинал | `ru` |
| `SHOW_ORIGINAL` | `yes` — под переводом мелко показывать оригинальный заголовок | `no` |

**Частота:** строка `cron: "*/30 * * * *"`. Например, `"0 * * * *"` значит раз в час.

**Посмотреть, как прошёл запуск:** Actions → любой запуск → шаг *Collect and send news*.

## Полезно знать
- GitHub запускает расписание с опозданием 5–15 минут. Это нормально.
- Файлы `state.json` и `docs/data.json` бот создаёт и обновляет сам. Не удаляйте их.
- Плитки на странице и строка в сообщениях обновляются раз в ~30 минут вместе с ботом. Графики TradingView на странице живые, в реальном времени.
- Котировки Yahoo могут запаздывать на 10–15 минут. Курсы рубля — официальные курсы ЦБ на день.
- Если источник новостей или котировок временно не отвечает, бот его пропускает. В вечерней сводке появится строка «⚠️ Не отвечают несколько часов: …».
- Перевод бесплатный: Google Translate, если он не ответит — MyMemory, если не ответят оба — придёт оригинал.
- Если указать chat id группы, кнопка будет открывать страницу в браузере, а не внутри Telegram: так устроен Telegram.

## Запуск на своём компьютере или сервере (необязательно)
Нужен Python 3.9+. Для картинки с графиками: `pip install matplotlib` (без него всё остальное работает).
```bash
export TELEGRAM_BOT_TOKEN="..."   # в Windows: set TELEGRAM_BOT_TOKEN=...
export TELEGRAM_CHAT_ID="..."
python news_bot.py --test      # проверить связь с Telegram
python news_bot.py --dry-run   # посмотреть новости в консоли, ничего не отправляя
python news_bot.py             # обычный запуск
```
